# 库存模块：批量清货损益公式说明

## 结论先行

库存成本推演模块已将批量清货从“按产品成本估算回收”改为“按 ASP 估算回收”，并补齐采购成本、头程成本和当月仓储费，输出完整的批清 P&L。

包装计费已改为自动判定：用户只需输入单品包装长、宽、高（cm）与含包装实际重量（kg），系统自动生成 Amazon 计费体积、Size Tier、Dimensional Weight 和 Shipping Weight。

月仓储基础费率不再支持手动输入数字。用户直接选择 Amazon 淡季或旺季，系统再按普通商品/危险品及自动判定的 Size Tier 匹配费率。

## 包装与 Shipping Weight 自动计算

```text
三边先从大到小排序
单件体积(ft³)       = 长(cm) × 宽(cm) × 高(cm) ÷ 28,316.846592
实际重量(lb)         = 实际重量(kg) × 2.20462262
原始体积重(lb)       = 长(in) × 宽(in) × 高(in) ÷ 139
Decision Weight      = max(实际重量, Dimensional Weight)
Length + Girth       = 最长边 + 2 × (次长边 + 最短边)
```

系统按 Decision Weight、三边和 Length + Girth 自动匹配 Small/Large standard、Bulky 或 Extra-large。Small standard 与 Extra-large 150+ lb 使用实际重量作为原始 Shipping Weight；其他档位取实际重量和体积重的较高值。Standard 且不足 1 lb 时向上取到 0.1 lb，其他档位向上取整磅。

## Amazon 月仓储季节

- 淡季：1–9 月。普通商品 Standard-size / Oversize 基础费率分别为 `$0.78 / $0.56` 每 cu ft；危险品分别为 `$0.99 / $0.78`。
- 旺季：10–12 月。普通商品 Standard-size / Oversize 基础费率分别为 `$2.40 / $1.40` 每 cu ft；危险品分别为 `$3.63 / $2.43`。
- 当前月仓储费、批清当月仓储分摊和未来推演首月使用用户所选季节；未来推演第 2 个月起按月份自动跨季。

## 库存移除费与现金流符号

移除费按自动判定的 Size Tier 与 Shipping Weight 匹配 Amazon 2026 rate card。Standard-size 超过 2 lb 时：

```text
单件移除费 = $2.89 + ceil(Shipping Weight − 2 lb) × $1.06

11 lb 单件移除费 = $2.89 + (11 − 2) × $1.06 = $12.43
600 件总移除费   = 600 × $12.43 = $7,458.00
```

计算引擎内部保留正数 `$7,458.00` 作为成本绝对值，用于比较未来持有成本与移除成本；页面、复制和 Excel/CSV 按现金流出显示为 `−$7,458.00`。单件移除费仍显示正数费率 `$12.43/件`。

## 长期仓储费 / 老化库存附加费

系统按 2026 Amazon aged inventory surcharge 档位估算：

| 库龄 | 体积费率（$/cu ft） | 最低按件费 |
| --- | ---: | ---: |
| 0–180 天 | 0 | 0 |
| 181–210 天 | 0.50 | 0 |
| 211–240 天 | 1.00 | 0 |
| 241–270 天 | 1.50 | 0 |
| 271–300 天 | 5.45 | 0 |
| 301–330 天 | 5.70 | 0 |
| 331–365 天 | 5.90 | 0 |
| 366–455 天 | 6.90 | 0.30/件 |
| 456 天以上 | 7.90 | 0.35/件 |

```text
体积口径费用       = 老化库存数量 × 单件体积 × 对应档位体积费率
最低按件口径费用   = 老化库存数量 × 对应档位最低按件费
预计老化库存附加费 = max(体积口径费用, 最低按件口径费用)
```

- 未填写入仓日期时，当前库龄、老化库存数量、当前老化库存费和未来库龄推演均显示“待计算”，不再把库存误当成 0 天并继续推演。
- 缺少有效入仓日期时，未来持有成本合计和方案比较也显示“待计算”；页面仍保留可确定的月仓储费明细，但不把它冒充完整持有成本。
- 当前日期早于入仓日期时视为日期异常，同样暂停库龄费推演，不再按 0 天计算。
- 服饰、鞋、箱包、珠宝和手表在 181–270 天档位豁免；用户勾选该类目后，这三个档位按 `$0` 计算，271 天起恢复正常费率。
- “手动老化库存体积费率”只覆盖已确认库龄所对应档位的 `$ / cu ft`，不能代替入仓日期，也不取消 181–270 天类目豁免；366 天及以上的 `$0.30 / $0.35` 最低按件费继续保留，避免手动费率导致少算。
- 页面模型以单一入仓日期做情景估算；Amazon 实际按每月 15 日库存快照及 FIFO 库龄分布计费，最终应以 Seller Central 账单为准。

## 计算公式

设：

- `Q`：本次清货数量，最多不超过当前库存
- `ASP`：平均 FBA 售价，USD/件
- `R`：预计回收率，默认 7.5%，提供 5% / 7.5% / 10% 情景
- `C`：采购成本，USD/件
- `F`：头程成本，USD/件
- `S`：本月仓储费，USD/件
- `P`：Liquidations processing fee，USD/件

```text
预计毛回收       = Q × ASP × R
Referral fee     = 预计毛回收 × 15%
Processing fee   = Q × P
预计净回收       = 预计毛回收 − Referral fee − Processing fee
采购成本合计     = Q × C
头程成本合计     = Q × F
本月仓储分摊     = Q × 单件体积 × 当前月总仓储费率
批清 P&L         = 预计净回收 − 采购成本合计 − 头程成本合计 − 本月仓储分摊
预计亏损         = max(0, −批清 P&L)
```

其中，预计净回收和批清 P&L 都保留正负号，不再把负净回收截断为 0。每件回收金额及 Referral fee 先按美元美分四舍五入，再乘清货数量，避免页面明细与合计因半美分产生差异。

## 输入与结果口径

- ASP 是回收金额的计算基数，采购成本不再参与毛回收计算。
- 15% Referral fee 只对预计毛回收计提，不对 ASP 全额计提。
- 包装长、宽、高与实际重量任一缺失时，不生成 Size Tier、Shipping Weight、移除费或完整批清 P&L，也不会自动套最低费率。
- Processing fee 按系统自动判定的 Size Tier 与 Amazon Shipping Weight 匹配。
- 月仓储费率只选择淡季/旺季，不允许手动输入任意数字；Size Tier 与危险品费率由系统自动匹配。
- 当前模块直接输入 USD 采购成本和 USD 头程成本，不做 RMB 汇率换算。
- 头程输入框留空表示“成本未知”，不会生成完整 P&L；如确认无头程成本，需要明确输入 `0`。
- P&L 只扣一次本月仓储费，不扣未来仓储费和老化库存费。
- 采购成本、头程属于历史成本，因此这是全成本损益视角；做“今天清货还是继续卖”的增量决策时，还需要单独看未来现金流。

## 验证样例

用 Amazon 示例口径验证现金回收部分：

```text
ASP                  $20.00
回收率                7.5%
预计毛回收            $1.50
Referral fee 15%      $0.23
Standard 0.2 lb 处理费 $0.25
预计净回收            $1.02
```

自动化测试同时覆盖：包装三边自动排序、cm³ 转 ft³、kg 转 lb、体积重/实重比较、Size Tier、Shipping Weight 取整、淡旺季选择、危险品仓储费率、未来月份自动跨季、ASP 基数、负净回收、Processing fee 重量边界、入仓日期缺失时不误算、箱包类 181–270 天豁免、366 天后最低按件费，以及完整 P&L。

## 假设与限制

- 实际回收率受 ASIN 销售历史、库存状态和清算商报价影响，5%–10% 仅用于情景估算。
- 实际 Size Tier、Shipping Weight 和 Processing fee 以 Seller Central 账单为准。
- Amazon 可能要求危险品或其他 special handling 商品使用 Bulky/Oversize 移除费率；如 Seller Central 的 rate card 与自动判定不同，应使用手动单件移除费覆盖。
- 老化库存费目前按一个入仓日期估算，不能还原同一 ASIN 多批次库存的 FIFO 年龄分布。
- 批清 P&L 不含税费、关税追加、未来仓储费、老化库存费和其他异常扣费；老化库存费仅在持有成本与方案对比区域单独展示。
- 当前月仓储分摊沿用本库存模块的基础仓储费率及适用的库容利用率附加费。
